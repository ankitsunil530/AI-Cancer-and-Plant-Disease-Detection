# AI Cancer and Plant Disease Detection

An AI-powered system for detecting cancer and plant diseases using Convolutional Neural Networks (CNNs). Designed for medical and agricultural applications with a focus on image-based diagnosis.

## Features
- Image classification using CNNs
- Cancer and plant disease detection
- Training and evaluation scripts
- Dataset handling and preprocessing

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV, numpy, pandas

## Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/ankitsunil530/AI-Cancer-and-Plant-Disease-Detection.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
- Place your images in the data folder.
- Run training or inference scripts as described in the code.
